# DFT Study of Molecular Interactions

## Overview

This project presents a computational investigation of molecular
interactions using Density Functional Theory (DFT).

## Objectives

* Optimization of molecular structures
* Analysis of electronic properties
* HOMO-LUMO analysis
* FTIR analysis
* UV-Vis analysis
* Non-covalent interaction (NCI) analysis

## Computational Methods

The molecular structures were optimized using Density Functional Theory(DFT).
